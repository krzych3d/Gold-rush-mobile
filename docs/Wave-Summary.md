# Opcjonalne podsumowanie fali / Optional wave summary

Raport jest dostępny po każdej ukończonej fali przez przycisk **WYNIK / REPORT**. Opcja **Pokazuj podsumowanie po każdej fali** w Ustawieniach otwiera go automatycznie; jest domyślnie wyłączona, a wybór jest zapisywany lokalnie. Podczas wyświetlania raportu licznik przygotowania kolejnej fali nie biegnie. Zamknij raport przyciskiem Wznów przygotowanie lub Android Back.

Pokazujemy wyłącznie rzeczywiście dostarczone złoto (nie sam łup niesiony przez jednostkę), odsetki, presję skarbców, straty najeźdźców i obrońców obu stron oraz bilans skarbca od rozpoczęcia ataku. Zakupy sprzed ataku nie są naliczane drugi raz. Raport nie przyznaje złota ani EXP i nie modyfikuje rozgrywki. Samouczek nie wyświetla raportu. Interfejs obsługuje polski i angielski oraz oba obroty telefonu.

Test Godot weryfikuje statystyki, ustawienia, ręczne i automatyczne wyświetlanie, zatrzymanie zegara oraz brak zmian złota.
